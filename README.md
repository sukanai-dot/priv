# Reel's Love Dashboard 💕

A cute and interactive React website made with love, chaos, and too much missing you.

## Features

- 💌 **Love Notes** - Random cute messages to brighten your day
- 😂 **Miss Meter** - Scientifically inaccurate but emotionally correct
- 🌸 **Reasons I Love You** - Unlimited reasons available
- 🔮 **Reel Fortune** - Your daily relationship prophecy
- 🚨 **Emergency Button** - For extreme missing-her situations

## Tech Stack

- **React** - UI library
- **Vite** - Fast build tool
- **Tailwind CSS** - Utility-first CSS framework

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The build artifacts will be stored in the `dist/` directory.
